DE WISKUNDE VAN MEHDI

Nederlandstalige webapp om rekenen en vraagstukken te oefenen.

Onderdelen:
- Optellen
- Aftrekken
- Vermenigvuldigen
- Delen
- Oefeningen
- Vraagstukken

Elk vraagstuk bestaat uit 4 stappen:
1. Voor
2. Bewerking
3. Antwoordzin
4. Controleren

De leerling kan pas naar de volgende stap wanneer het antwoord juist is.

De app werkt op GitHub Pages en gebruikt geen server.
